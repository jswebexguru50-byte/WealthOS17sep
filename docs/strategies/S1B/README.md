# S1B — VPA trough reversal

The canonical user prompt is [S1B.original.txt](S1B.original.txt), copied verbatim from the attachment supplied on 23 September 2026. S1b and S1B are aliases for this specification.

S1B is separate from S1A. It finds a bullish reversal at the pullback trough or within the next two sessions. It does not require a third-leg reclaim and permits a 10–90% pullback, provided the trough low remains above the original low.

Run it with `scripts/market_data/vpa_s1b_screen.py --as-of-date YYYY-MM-DD`.
