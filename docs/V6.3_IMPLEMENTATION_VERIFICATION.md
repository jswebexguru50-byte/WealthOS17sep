## 4. Position Sizing Policy

Position sizing in `generateSignalsFromBars()` and `ExecutionSimulator` is governed by explicit institutional policies:
1. **Adaptive Capital Protection Sizing (`Arm C`)**: Calls `calculateAdaptivePositionSize()` in `CapitalProtectionEngine.ts`, enforcing 1.5% default target risk, 2.0% hard ceiling, 8.0% single-stock cap, 5.0% ADV liquidity limit, and adverse gap scaling.
2. **Standard Institutional Risk Policy (`Arm A / Arm B`)**:
   $$\text{Shares} = \left\lfloor \frac{\text{Capital} \times 0.015}{\text{Entry Price} - \text{Stop Price}} \right\rfloor$$
3. If computed shares $\le 0$ or risk per share $\le 0$, execution fails closed with:
   `DATA_INSUFFICIENT: POSITION_SIZING_UNDEFINED`.
   Arbitrary `100 shares` defaults are strictly prohibited.

## 5. Real Execution Simulator Event Loop

`ExecutionSimulator.simulate()` implements a deterministic, multi-asset chronological event loop.

### Event Order per Timestamp $T$:
1. **PIT Validation**: Ensures `bar.availableAt <= bar.timestamp`.
2. **Pending Exit Execution**: Fills exits scheduled from previous bar at `currentBar.open`.
3. **Eligible Signal Execution**:
   - Enforces `signal.timestamp < bar.timestamp`.
   - Signals generated on bar $T$ **cannot fill on bar $T$** (rejects as `SAME_BAR_EXECUTION`).
   - Fills strictly on `NEXT_TRADABLE_BAR_OPEN` (skipping non-tradable holidays).
   - Validates available cash ($Cash \ge Notional + Costs$).
4. **Active Position Evaluation**:
   - Checks high/low against initial stop and target.
   - If both stop and target touched in same bar, `CONSERVATIVE_STOP_FIRST` mandates `exitReason = STOP_LOSS`.
   - Schedules pending exit for the **next tradable bar open**.
5. **Continuous Multi-Asset MTM**:
   - At every timestamp $T$, computes total portfolio equity across all concurrent positions:
     $$\text{Equity}(T) = \text{Cash}(T) + \sum_{i \in \text{Positions}} \text{Quantity}_i \times \text{MarkPrice}_i(T)$$
   - Verified across simultaneous holdings (e.g., INFY, TCS, RELIANCE, SBIN).
6. **Portfolio Snapshot**: Appends `{ timestamp, equity }` to `equityCurve`.
