## 5. Known defects to fix first (from reviewers; failing tests reproduce them)
**S1 (P1–P12):** point-in-time row with fake period end `LATEST` must be rejected; unknown scope rejected at runtime; annual must be emitted as `ANNUAL` (spec 5.1 step 4); a later PROVIDER value must not supersede a STATUTORY value (retain conflicts, statutory wins); same value from statutory after provider must record the statutory tier; `availableAt` with offsets ordered as instants not strings; a derived quarter must not be calculable when its YTD input failed reconciliation; Trendlyne INR scaling must come from the catalogue not a source-name regex; percent metric outside 0..100 flagged or rejected; legacy aliases `roe_pct`/`roce_pct` must resolve; invalid `availableAt` rejected; empty `isin` rejected.
**S2 (ADV1–ADV9):** unit must be part of the fact key (a rupee value must not become a vintage of a crore fact); reverting to an earlier value with identical `availableAt` must not be silently dropped; a re-write carrying a blocking quality flag or `quarantined` must not be swallowed as UNCHANGED; impossible calendar dates rejected on write; period type must match the span (a 12-month DISCRETE_Q rejected); **the guard must treat the live `fere_evidence.db` as production**; schema checksum must be line-ending independent (Windows autocrlf); same-tier sources that disagree must be surfaced by the read path.
**S8:** parity test — a wrong-number injection must be caught identically on every provider path.
Also: 9 type errors (§4), the missing `readiness/` module, and all undone slices.
